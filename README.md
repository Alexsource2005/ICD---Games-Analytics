"# ICD---Games-Analytics" 
Integrantes:
  Alessandra Cardoso Fernandes (Alexander)

Tema do projeto: 
  Dados sobre o mercado de jogos digital com recorte específico para o PC (Steam, Epic Games e GoG Galaxy)

Abordagem de coleta de dados:
  APIs: SteamWorks WEB API, SteamSpy API, GraphQL (epic games/JSON), Datasets da comunidade(derivados que forem encontrados no github), API REST do catalogo GOG
  Web scrapping: Principalmente na busca de dados para a Epic Games e a GOG, será realizado em suas páginas individuais de produtos em busca de resenhas ou comentários especificos de usuários. e especificamente na página https://www.nerdmaldito.com/2020/05/lista-com-todos-os-jogos-dados-pela.html para buscar as datas em que jogos ficaram gratuitos na Epic Games desde o final de 2018.
